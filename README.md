# Home Inventory

A phone-friendly home inventory for insurance: record fixtures, furniture and fittings by room, with age, purchase details, value, cover type (Buildings or Contents) and photos.

- Everything is stored on the phone itself (nothing is uploaded anywhere).
- Use "Back up everything" regularly and keep the backup file in Google Drive or email it to yourself.
- Open the site in Chrome on Android and choose "Install and create shortcut" to put it on the home screen.
